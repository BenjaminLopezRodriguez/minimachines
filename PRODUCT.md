# Product

## Register

brand

## Users

Developers who already use a coding agent and a terminal. They want cloud compute for builds, tests, and agent work without managing a server first.

## Product Purpose

Give coding agents a dedicated cloud workspace. Success for this public site means understanding the product, installing the CLI, authenticating, and running a first command on a real machine.

## Brand Personality

Precise, capable, approachable. Keep Mini Machines’ identity while making a stronger visual change. The user chose elevated minimalism, with the tactile, restrained control finishes of Linear and Apple as references.

## Anti-references

Waitlist gates in front of available software, fictional terminal commands, unsupported persistence claims, decorative dashboards, and text animations that delay reading.

## Design Principles

- Make the next useful action clear.
- Teach the real workflow with supported commands.
- Put prerequisites, compute costs, and workspace lifetime beside the decisions they affect.
- Keep learning publicly accessible and account actions protected.
- Use visual refinement to clarify controls and hierarchy.

## Accessibility & Inclusion

Target WCAG 2.2 AA: keyboard access, visible focus, readable contrast, generous touch targets, responsive layouts, and reduced-motion support. Never convey status using color alone.
